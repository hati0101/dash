# 운영 대시보드

개인 프로젝트 작업 현황을 한 화면에 모아 보는 정적 대시보드입니다. GitHub Pages(`docs/`)로 게시합니다.

## 보안 구조

- 게시되는 데이터는 `docs/data.enc.json` 하나이며 **암호문**입니다.
  - 비밀번호 → PBKDF2-SHA256(60만 회) → AES-256-GCM, gzip 압축 후 암호화
- 페이지는 비밀번호를 입력받아 **브라우저 안에서만** 복호화합니다. 서버로 비밀번호를 보내지 않습니다.
- 평문 원본(작업 기록, 주제, 설정)은 `.gitignore` 허용 목록 방식으로 커밋에서 제외됩니다.
- 게시 전 `tests/verify.py`가 다음을 확인합니다. 하나라도 실패하면 게시하지 않습니다.
  - 왕복 복호화
  - 틀린 비밀번호 거부
  - 변조 감지
  - 평문 유출 여부
- 주제 보내기: 페이지에서 쓴 주제는 같은 키로 암호화되어 이슈 본문에 암호문으로만 남습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `build.py` | 로컬 기록 수집 · 민감정보 마스킹 · 암호화 |
| `encrypt.mjs` | 암호화/복호화 (Node 내장 crypto) |
| `topics.py` | 주제 가져오기 · 분배 · 진행 베이스 · 검토 메모 |
| `publish.ps1` | 가져오기 → 생성 → 검증 → push |
| `docs/` | 게시되는 정적 페이지 |

## 사용

```powershell
.\publish.ps1 -NewPassword   # 처음 또는 비밀번호 변경
.\publish.ps1                # 평소 갱신
```
